# Benchmarks

В каталоге находятся наборы грузинских заданий для оценки языковой модели.

Основной набор — `georgian/language_benchmark_v3.json`. Он был составлен для оценки трёх характеристик модели:

- продолжение текста — 18 заданий разных жанров;
- знание фактов о Грузии — 18 заданий;
- удержание контекста — 18 заданий.

Каждое задание содержит идентификатор, исходный грузинский текст и метаданные. Для двух последних категорий дополнительно указаны эталонный ответ и четыре варианта для ранжирования. Контекстные задания также содержат контрольный промпт без ключевой информации.

### Схема оценивания

```text
language_benchmark_v3.json
              ↓
       Проверка заданий
              ↓
      Экспортированная GGPT
              │
              ├── Генерация в пяти режимах
              │          ↓
              │    generations.jsonl
              │
              └── Вероятностная оценка
                         ↓
                    scores.jsonl
```

### Запуск

```bash
python scripts/benchmark_v3.py \
  --model artifacts/exports/MODEL_NAME \
  --dataset benchmarks/georgian/language_benchmark_v3.json \
  --device cuda \
  --output reports/benchmarks/RESULT_NAME
```
