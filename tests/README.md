# Tests

Тесты охватывают компоненты модели, обработку данных, обучение и оценивание.

### Структура

- `analysis/` — расчёт метрик документов, агрегация статистик и сохранение результатов EDA.
- `data/` — чтение токенизированного корпуса и формирование последовательностей.
- `model/` — конфигурация, компоненты Transformer и полный forward pass.
- `training/` — оптимизация, scheduler, валидация, checkpoints и управление экспериментами.
- `inference/` — авторегрессионная генерация.
- `benchmark/` — загрузка заданий, вычисление вероятностей, экспорт модели и сбор результатов.

### Запуск

Все тесты:

```bash
python -m pytest -q
```

Проверка отдельных компонентов:

```bash
python -m pytest -q tests/model
python -m pytest -q tests/data
python -m pytest -q tests/training
python -m pytest -q tests/benchmark
```

Для проверки работы с полными экспериментами дополнительно используются тесты интеграции CLI, сохранения состояния и возобновления вычислений.
