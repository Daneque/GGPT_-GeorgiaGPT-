# Tokenization

Подготовка токенизатора была разделена на выборку обучающих документов, обучение Byte-level BPE и кодирование корпуса.

В `prepare_sample.py` реализован воспроизводимый отбор 100 тысяч документов из обучающей части FineWeb2, без включения валидационных документов.

Скрипт `train_bpe.py` обучает токенизатор с размером словаря 16 384 и сохраняет его в `tokenizer.json`. Для служебных токенов использованы идентификаторы `BOS=0`, `EOS=1`, `PAD=2`.

После обучения токенизатора `encode_corpus.py` последовательно обрабатывает исходные Parquet-файлы с учётом разбиения train/validation. Результаты записываются в `train.bin` и `val.bin` в формате `uint16`.

Кодирование поддерживает возобновление после прерывания. Для проверки согласованности этапов сохраняются манифесты входных данных, токенизатора и результатов кодирования.

### Запуск

Подготовка выборки:

```bash
python scripts/tokenizer/prepare_sample.py --n-docs 100000 --seed 1729
```

Обучение токенизатора:

```bash
python scripts/tokenizer/train_bpe.py \
  --n-docs 100000 \
  --seed 2718 \
  --vocab-size 16384 \
  --output-dir artifacts/tokenizer/bpe_100k_16384
```

Кодирование корпуса:

```bash
python scripts/tokenizer/encode_corpus.py
```
