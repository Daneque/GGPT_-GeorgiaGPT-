# Data

Модуль отвечает за чтение исходного корпуса и формирование обучающих последовательностей.

Для работы с FineWeb2 реализован `ParquetCorpus`, позволяющий последовательно обрабатывать Parquet-файлы без загрузки всего корпуса в оперативную память.

После токенизации данные поступают в `TokenWindowDataset` из бинарных файлов `train.bin` и `val.bin`. Чтение выполняется через `numpy.memmap`. Из последовательности извлекается окно длиной 513 токенов, которое разделяется на входные токены и целевые значения со сдвигом на одну позицию.

За формирование батчей отвечает `token_loader.py`. При обучении окна случайно выбираются из всего корпуса с возвращением. Размер виртуальной эпохи задаётся параметром `train_windows`, а для валидации используется фиксированный набор равномерно распределённых окон.

Состояние семплера сохраняется вместе с checkpoint, что позволяет восстановить последовательность батчей после прерывания обучения.

### Запуск

Загрузка корпуса и формирование train/validation-разбиения:

```bash
python scripts/data/download_fineweb2.py
python scripts/data/split_fineweb2.py
```

Проверка загрузчика данных:

```bash
python -m pytest -q tests/data
```
