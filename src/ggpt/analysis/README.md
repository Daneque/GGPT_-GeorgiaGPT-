# Analysis

Модуль предназначен для исследования характеристик документов FineWeb2. Анализ полного обучающего корпуса выполняется потоково, без загрузки всех документов в оперативную память.

В `metrics.py` реализован `DocumentProfiler`, вычисляющий длину текста, распределение письменностей, наличие ссылок, повторяющихся строк и другие характеристики документов.

Агрегация результатов выполняется в `statistics.py`. Статистики и гистограммы обновляются по мере поступления батчей, без накопления всех документов в оперативной памяти.

### Схема обработки

```text
Parquet-файлы FineWeb2
         ↓
    Чтение батчами
         ↓
    DocumentProfiler
         ↓
    Метрики документов
         ├── CorpusStatistics → summary.json
         └── DocumentMetricsWriter → metrics.parquet
```

В `eda.py` реализован общий процесс анализа, а `full_eda.py` обеспечивает обработку полного корпуса с разбиением по группам строк Parquet. Промежуточные результаты сохраняются отдельно, что позволяет возобновлять анализ после прерывания.
