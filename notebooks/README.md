# Notebooks

В каталоге находятся исследовательские ноутбуки, использованные при подготовке данных и выборе токенизатора.

### `01_fineweb2_eda.ipynb`

Проводился анализ грузинского раздела FineWeb2. Исследовались размеры документов, распределения текстовых характеристик и признаки качества корпуса. Для обработки полного обучающего раздела использовались потоковые методы из `ggpt.analysis`.

### `02_bpe_analysis.ipynb`

Сравнивались Byte-level BPE-токенизаторы с разными размерами обучающей выборки и словаря.

Анализировались длины токенизированных последовательностей, эффективность кодирования и распределения токенов. Результаты сравнения использовались при выборе окончательной конфигурации BPE со словарём 16 384 токена.

Реализации подготовки данных и токенизатора находятся в `scripts/data/` и `scripts/tokenizer/`.
