# Notebooks

В каталоге находятся исследовательские ноутбуки, использованные при подготовке данных и выборе токенизатора.

### `01_fineweb2_eda.ipynb`

Проводился анализ грузинского раздела FineWeb2. Исследовались размеры документов, распределения текстовых характеристик и признаки качества корпуса. Для обработки полного обучающего раздела использовались потоковые методы из `ggpt.analysis`.

### `02_bpe_analysis.ipynb`

Сравнивались Byte-level BPE-токенизаторы с разными размерами обучающей выборки и словаря.

Анализировались длины токенизированных последовательностей, эффективность кодирования и распределения токенов. Результаты сравнения использовались при выборе окончательной конфигурации BPE со словарём 16 384 токена.

### `03_comparison.ipynb`

Сопоставляются пять обученных моделей: 40M/200k и 49M после 100k, 200k, 300k и 400k шагов. Рассматриваются динамика обучения, результаты Benchmark v3, влияние контекста, режимы декодирования и качественные оценки грузинских продолжений.

Для повторного выполнения используются JSON/JSONL-файлы из `data/evaluation/ggpt_v3/`. Повторная генерация текстов и загрузка весов не требуются.

### `04_inference.ipynb`

Демонстрируется свободное продолжение грузинского текста моделью 49M/300k. Загружается готовый артефакт из `artifacts/exports/llama_49m_300k/`, используется режим Top-k (`k=40`, `temperature=0.8`). В последней ячейке задаётся собственный промпт;

Файл весов `model.pt` отслеживается через Git LFS. После клонирования репозитория для его получения используется `git lfs pull`.

Реализации подготовки данных и токенизатора находятся в `scripts/data/` и `scripts/tokenizer/`. Код загрузки модели и генерации расположен в `src/ggpt/inference/`.
